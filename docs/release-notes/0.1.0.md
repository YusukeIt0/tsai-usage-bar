First release.

- Menu bar items for Claude Code and Codex 5-hour (H) and 7-day (W) limits; each can be turned on or off, and reordered with ⌘-drag.
- Popover with both windows, bars, and local reset times.
- Remaining or used percentage; Japanese and English (automatic or manual).
- Codex values from the official `codex app-server`; Claude Code values from its official `statusLine`, keeping your existing status line.
- One-command install, update, and uninstall without sudo.

This build is not notarized by Apple. The installer verifies the SHA-256 checksum and code signature before installing.
