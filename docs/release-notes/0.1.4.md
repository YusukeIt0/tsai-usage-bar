- **Update notice:** about once a day the app checks this repository's GitHub Releases. When a newer version exists, the popover and Settings show it with an **Update** button that installs it (settings are kept). Settings also shows the current version and a manual check.
- **Eight languages:** English, 日本語, 繁體中文, 简体中文, 한국어, Français, Deutsch and ไทย, the same set as the TripSurf website. Automatic picks the first supported macOS language, otherwise English. Dates, times and remaining durations follow the chosen language.

This build is not notarized by Apple. The installer verifies the SHA-256 checksum and code signature before installing.
