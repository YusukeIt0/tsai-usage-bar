- **GitHub Actions:** a new menu bar item `M` shows this month's free Actions usage for private repositories (public repositories are free with no limit), as remaining or used percent like the other items. Connect in Settings → **Connect GitHub**: the code is copied and the browser opens. The app can only read your plan and billing usage. Resets at 00:00 UTC on the 1st; GitHub's totals can lag by a few hours.

This build is not notarized by Apple. The installer verifies the SHA-256 checksum and code signature before installing.
